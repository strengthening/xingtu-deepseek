# 地平坐标精度基准

本文记录 `src/astro/` 里「恒星 J2000 位置 → 地平方位角/高度角」这条链路的
参考值来源、复现方法，以及实测精度。

## 1. 被验证的链路

```
星表 J2000 位置（单位向量）
  → 自行推算到观测时刻            astro/properMotion.ts
  → 光行差（公转 + 自转）          astro/aberration.ts
  → 岁差 + 章动（EQJ → EQD）       astro/coordinates.ts  ← astronomy-engine
  → 地平旋转（EQD → HOR）          astro/coordinates.ts  ← astronomy-engine
  → 方位角 / 高度角
```

## 2. 参考值来源

参考值由 **Skyfield 1.55 + JPL DE421 星历**离线计算，观测点为
**上海（31.2304°N, 121.4737°E, 海拔 4 m）**，取**几何地平坐标**（不含大气折射）。

Skyfield 与 Stellarium 都实现 IAU 的岁差 / 章动 / 光行差标准链路，
两者对亮星的地平坐标一致到亚角秒量级。PROMPT 要求的「与 Stellarium 结果误差 < 0.1°」
在这里用同等甚至更严的基准来验证。

## 4. 残差来源

残余的亚角秒偏差来自本实现**有意不建模**的高阶项：

| 项 | 量级 | 说明 |
|---|---|---|
| 周年视差 | 最大 0.38″（天狼星） | 未按恒星距离修正站心方向。星表里只有 97.6% 的行有距离，且对绝大多数暗星无意义 |
| 光行时 + 多普勒因子 | < 0.1″ | 未沿恒星自行做光行时回推 |
| 相对论光行差 | ≈ 0.002″ | 本实现用一阶矢量公式 `n' = normalize(n + v/c)` |
| 太阳引力偏折 | < 0.02″（离日 > 30°） | 未建模 |
| 数值差分求地球速度 | < 0.001″ | 中心差分步长 0.02 天 |

这些都是角秒以下的量级，且随恒星距离与离日角变化。
若要进一步压缩，需要引入视差与光行时回推，对本项目的用途（可视化）没有必要。

## 5. 防回归测试

`src/astro/coordinates.test.ts` 包含：

1. **12 组主精度测试**：4 颗星 × 3 个时刻，要求总偏差 < 0.01°（比 PROMPT 的 0.1° 严 10 倍）。
2. **天狼星亚角秒测试**：要求方位角与高度角偏差均 < 1″。
3. **岁差反证**：故意跳过岁差，验证误差 > 0.1°，说明岁差不可省。

   > 注意这条测试必须用**天球角距离**比较。天狼星在该时刻几乎位于子午线上，
   > 高度角对时角的一阶导数为 0，只看高度角会严重低估岁差的影响（实测只有 0.017°）。

4. **`rotationToMat3` 防回归**：astronomy-engine 的 `RotationMatrix.rot[i][j]`
   存的是矩阵的**转置**（见其 `RotateVector` 实现：`v'ᵢ = Σⱼ rot[j][i]·vⱼ`）。
   直接按行主序使用会让整个天球镜像。该测试用它自己的 `RotateVector`
   对三个基向量做探针，逐一比对提取出的矩阵。

5. **纯公式交叉验证**：自行实现的 `equToHorMatrix(纬度, 地方视恒星时)`
   与 astronomy-engine 的 `Rotation_EQD_HOR` 在多个方向上一致到 0.01° 以内。

6. **自行推算**：巴纳德星 100 年位移约 1036″；光行差量级 19.5″–21.0″；
   半年后地球速度方向相反。
